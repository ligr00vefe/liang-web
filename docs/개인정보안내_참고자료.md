# 개인정보 문의 동의 안내 참고 자료

- 우노가구 제작 문의: https://unogagu.com/contact/contact.php
  - 상담 목적, 수집 항목, 상담 종료 후 6개월 보유, 담당자 안내 구조를 참고.
- 이프하우스 프로젝트 상담: https://ifhouse.co.kr/board/urgency/urgency.html
  - 공간 가구 납품·제작 상담의 수집 목적·항목·기간·거부 안내 구성을 참고.

다른 업체의 문구·정책을 그대로 복사하지 않고 리앙 가구 실제 문의 항목으로 작성했다.
다른 업체의 연락처, 이메일, 수집하지 않는 정보, 회원·결제 조항을 가져오지 않았다.
리앙 가구의 확정된 보유기간은 상담 종료일로부터 6개월이며, 별도 사본은 운영자가 삭제한다.
고객 요청에 따라 동의 모달의 서비스 업체명 표와 내부 DB·서버 구성 설명을 삭제했다.
이 참고 자료는 법률 검토 완료나 개인정보 처리방침 전체 요건 충족을 보증하지 않는다.
