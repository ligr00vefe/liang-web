# 리앙 가구 문의 보유기간 관리 안내

공식 주소: https://liangfurniture.netlify.app
관리자: https://liangfurniture.netlify.app/admin-0c8debce

## 상담 종료와 삭제
- 관리자 → 제작 문의 관리 → 상세 보기 → 상담 종료 처리.
- 서버에 기록된 상담 종료 시각에서 달력 기준 6개월 후 삭제 대상이 됩니다.
- 매시 15분 정기 작업에서 기한이 지난 Netlify 문의 원문과 종료 기록을 삭제합니다. 한 번에 최대 5건 처리합니다. 초과분·실패분은 다음 실행에서 재시도합니다.
- 상담 다시 열기를 누르면 삭제 예약이 해제됩니다. 다시 종료하면 새 종료일을 기준으로 6개월을 계산합니다.
- 상담 종료 처리를 하지 않은 문의에는 종료일 기준 예약이 없습니다. 관리자가 상담 종료 시 반드시 처리해야 합니다.
- 기존 문의는 상담 진행 중으로 유지합니다. 과거 종료일을 임의로 정하지 않습니다.
- 관리자 문의 삭제는 기한과 관계없이 즉시 영구 삭제합니다.
- 이메일 알림 사본, CSV·다운로드 파일, 사용자가 별도로 만든 백업은 이 작업으로 삭제되지 않습니다. 운영자가 별도로 삭제해야 합니다. Netlify 내부 백업의 소거 시점까지 보장하는 기능은 아닙니다.

## 정기 실행 확인
Netlify 프로젝트 → Functions → inquiry-retention → 일정·실행 로그를 확인합니다. 정상 로그에는 삭제 건수만 남고 문의 내용은 남지 않습니다. 실패 로그가 있으면 DB·Forms 토큰 권한과 서비스 한도를 확인하고 Run now로 재실행합니다. 스케줄은 운영 배포에서만 작동합니다. 무료 한도 초과·장애·계정 정지 중에는 실행되지 않을 수 있으므로 운영자가 확인해야 합니다.

## 계정과 검수
- 관리자 → 계정 설정에서 현재 비밀번호 확인 후 새 비밀번호(12자 이상)를 설정할 수 있습니다. 변경 시 모든 기존 로그인이 종료됩니다.
- 현재 계정 비밀번호는 제작자가 임의 변경하지 않았습니다.
- 기능 검수는 대표가 직접 시공사례 등록·수정·삭제, 모바일 메뉴와 버튼을 확인합니다. 테스트 사례는 임시 이름으로 등록한 후 삭제합니다. 등록한 사례는 공개 목록에 노출됩니다.
- 화면 녹화물 제작은 기본 인계 범위에 포함하지 않습니다. 별도 요청 시 추가 200,000원으로 사전 협의합니다.
- 문의 폼은 공개되어 있으며 동의 옆 내용 확인 버튼 또는 동의 체크 시 안내 모달을 열 수 있습니다. 상담 종료 후 6개월 보관 기준을 안내합니다. 검수에는 가상 정보를 사용하고 접수 확인 후 테스트 문의를 삭제합니다. 이메일 알림 검수는 실제 수신 주소 등록·확인 후 진행합니다.

## 백업과 인계
- 관리자 시공사례 화면의 백업 다운로드는 시공사례 데이터와 업로드 사진의 JSON 사본입니다. 관리자 인증정보와 문의는 포함하지 않습니다. 다운로드 후 안전한 장소에 보관합니다.
- 복구는 제작자에게 백업 파일로 요청합니다. 기존 DB를 덮어쓰기 전에 별도 환경에서 검증합니다. 자동 복구 버튼·정기 백업·상시 장애 대응은 포함하지 않습니다.
- Netlify 문의는 Netlify 대시보드 Forms에서 CSV로 내보낼 수 있습니다. 보유기간에 맞춰 파일도 삭제합니다.
- 코드 저장소, Netlify·Neon 계정 권한, 운영 비용·사용량 확인 위치를 최종 인계 때 전달합니다. 유료 전환은 사전 승인 후 진행합니다.
- 카카오톡 상담 URL은 전달받은 뒤 푸터에 연결합니다. 전화번호도 확정된 번호를 받아 연결합니다.
- 개인정보 담당자는 박지훈 대표로 표시합니다. 미확정 전화번호·이메일은 공개하지 않습니다. 실제 수신 가능한 주소를 받은 뒤 알림 수신과 개인정보 문의 연락처를 반영합니다.
